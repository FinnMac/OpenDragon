Moving OpenDragon to the laptop

Everything a new Claude session on the laptop needs to carry on building OpenDragon. OpenDragon is an open-source recogniser built the way Dragon NaturallySpeaking 16 is built: features, acoustic network, word-graph search, lattices, then learning your voice. It is built only from published methods and open models.

Steps

  1. Copy Documents\OpenDragon-handover.zip (2.5 MB) from the desktop to the laptop, by OneDrive or a USB stick.
  2. Unzip it into the laptop's Documents folder, so the paths match the desktop's.
  3. Shut the desktop down. Nothing from OpenDragon is running on it.
  4. On the laptop, open the Claude app, start a session in Documents, and paste the prompt below.
Paste into the new session
Read Documents\OpenDragon\HANDOVER.md and PLAN.md, then continue Stage 0 of OpenDragon from where the hand-over says. Recreate the venv first.

  • To doWrite the results to STAGES.md, make the first commit, and check in with you.
